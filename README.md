
# Student Management System

My BCA project developed using PHP and MySQL.

## Features
- Add Student
- View Student Records
- Edit Student Details
- Delete Student
- Search Student Records

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- XAMPP

## How to Run
1. Install XAMPP.
2. Copy project folder into htdocs.
3. Start Apache and MySQL.
4. Open http://localhost/student_management/
